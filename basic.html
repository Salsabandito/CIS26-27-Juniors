HTML Lists

There are 3 types of HTML lists

Unordered Lists

Unordered lists are lists that have bullet points to the left of each list item. These lists are contained in a <ul> tag. Each item in the list is contained in an <li> tag.

  • Cedric
  • Ian
  • Alex
  • Levi
  • Martin
  • Angus
  • Kaleb

NOTE: Unordered lists are the base HTML structure used to create navigation.

Ordered Lists

Ordered lists are used to create a sequence of items or steps. These list items have a number, roman numeral, or alpha character to the left of each item. Like <ul> items, ordered list items are contained in <li> tags.

  1. Step 1: crack eggs
  2. Step 2: add milk
  3. Step 3: whisk eggs and milk
  4. Step 4: pour into a hot pan
  5. Step 5: stir until done

Absolute and Relative URLs

URL:Universal Resource Locator - aka web address

Absolute URLs: - A complete URL including the transfer protocol
ex:
https://resources.zybooks.com/WebProgramming/mediumCatv1.jpg

Some Absolute URLs are very long.

Relative URLs - This sepcifies a "relative" path to the webe resourse with no scheme or host name. (Protocol or domain) They refer to resources based on the current web address you are in.

An example is the link to the index.html file at the top of this section.

Section Links

A URL can point to a section, or FRAGMENT, of a document by adding a # and a fragment indentifer at the end of the URL.

EX:
https://en.wikipedia.org/wiki/computer_Sceince#History

The section listed after the # refers to an ID attribute. EX:
<section id="History"> - What the id attribute creates is call a fragment identifier.
